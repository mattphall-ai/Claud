# Apps

This repository holds standalone web apps, each in its own folder so they
don't overwrite one another.

- [`spelling-bee/`](spelling-bee/) — a clone of the New York Times Spelling
  Bee word game, with a generator for making new puzzles whenever you want.

## Running an app

```bash
cd spelling-bee
npm install
npm run dev
```

See each app's own `README.md` for details.
